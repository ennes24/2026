# 옥수수 수확량 예측 — 재현 패키지

미국 카운티 단위 기후·토양 데이터로 옥수수 수확량을 예측하고, 나아가 **2012년 대가뭄 같은
'흉작(붕괴)'의 위험을 미리 경고**하는 머신러닝 프로젝트입니다. 이 폴더의 파일만으로 데이터 로딩부터
최종 결과까지 **처음부터 끝까지 재현**할 수 있습니다.

## 폴더 구성

| 파일 | 내용 |
|---|---|
| **`analysis.ipynb`** | 전체 코드 + 실행 결과(표·그림)가 담긴 노트북. **데이터가 내장**되어 외부 파일 불필요. |
| **`explanation.md`** | 머신러닝을 처음 배우는 사람도 이해할 수 있는 **쉬운 설명 문서**. |
| **`requirements.txt`** | 필요한 라이브러리 목록. |
| **`README.md`** | 이 파일(실행 방법). |

## 실행 방법

### 방법 A — Google Colab (가장 간단, 설치 불필요)
1. [colab.research.google.com](https://colab.research.google.com) 접속 → `파일 > 노트북 업로드`
2. `analysis.ipynb` 업로드
3. 메뉴 → `런타임 > 모두 실행`
   - 데이터가 노트북에 내장되어 있어 **이 파일 하나만** 올리면 됩니다.
   - 한글 그래프가 깨지면 첫 셀 맨 위에서 한 번만 실행: `!apt-get -qq install -y fonts-nanum`

### 방법 B — 내 컴퓨터(로컬)
```bash
# 1) 라이브러리 설치
pip install -r requirements.txt

# 2) 주피터 실행
jupyter lab analysis.ipynb      # (또는  jupyter notebook analysis.ipynb)

# 3) 위에서 아래로 순서대로 셀 실행 (메뉴 → Run All)
```

> GitHub 웹에서 `analysis.ipynb` 를 클릭하면 **이미 실행된 표·그림이 그대로** 보입니다(출력 내장).

## 이 프로젝트가 하는 일 (요약)

1. **기본 예측** — 온도·강수·토양·7월 가뭄 등 14개 피처로 옥수수 수확량(bu/ac)을 예측.
   미래를 정직하게 평가하기 위해 **연도 순서로 분리**(과거로 배우고 다음 해를 맞힘)합니다.
2. **극단해 인식** — 표준 예측은 2012년 붕괴를 놓칩니다. 그래서 숫자 하나 대신
   **하방 위험(얼마나 나빠질 수 있나)** 을 예측하고, 그 구간이 실제로 80% 신뢰되도록 보정합니다.

자세한 원리와 결과 해석은 **`explanation.md`** 를 읽어보세요.

## 재현성

- 모든 모델에 **랜덤 시드 고정**(`random_state=0`) → 몇 번을 돌려도 같은 결과.
- 데이터 분리도 무작위가 아니라 **연도 순서** → 흔들림 없음.
- 필요 라이브러리는 `numpy`, `pandas`, `scikit-learn`, `matplotlib` **4개뿐**.
