# 프로젝트 종합 진단서 — 옥수수 수확량 예측 (ACDC)

> 현재 최고 모델: 옥수수 HistGradientBoosting, 14피처.
> 성능(3렌즈): 랜덤 CV **0.86** / GroupKFold **0.79** / 시간분할 **0.66** (RMSE 24.3 bu/ac).
> 이 문서는 데이터·피처·모델·검증·일반화·최신동향·실무 관점의 취약점을 진단하고,
> 중요도·대응·로드맵·ROI TOP 10을 정리한다. 모든 수치는 우리 실험 결과에 근거한다.

---

## 1. 데이터 진단

**규모**: 옥수수 34,627 카운티-연 (12개 주, 1981–2015, 1,113 카운티). 트리모델엔 충분.

**품질/편향/결측**
- **2015년 컷오프** — 가장 뜨거웠던 2016–2024가 빠짐. 온난화 신호가 실제보다 약하게 잡히고, 시나리오 정당성이 흔들리는 근본 원인.
- **공간 편향** — Corn Belt 12개 주만. 신호는 깨끗하나 결론이 벨트에 한정.
- **결측 구조** — USDM 7월 가뭄은 2000년부터(1981–99 NaN, 트리가 처리). 대두 재배지 밖은 타깃 NA로 제외. slope 결측이 특정 지역에 클러스터(MNAR). 원본 온도 293행이 '184일 제약' 위반(0.11%, 영향 미미).
- **정적 데이터의 한계** — 토양(soil2011)·관개(2012 스냅샷)는 연도 고정값이라 "그해 상태"를 못 담음.

**시계열 특성**
- 강한 기술추세(+1.7 bu/ac/년) + 연차 기상충격. 추세는 예측엔 필수, 인과해석엔 제거 대상(둘 다 처리함).
- **연차 날씨는 예측 불가**(자기상관 ≈0, 분산의 83%가 공간). → 미래 날씨는 예측이 아니라 시나리오로 다뤄야 함.

**공간 특성**
- 카운티 단위(필드 아님). 인접 카운티 간 공간 상관을 모델이 명시적으로 안 씀(트리는 각 행 독립 처리).

**부족한 데이터(영향 순)**
1. **생육기 내 시계열(월/순 단위)** — 지금은 계절 총합 + 7월 스냅샷만. 최대 공백.
2. **위성 식생지수(NDVI/EVI)** — 최신 연구의 최상위 예측변수. 우리 완전 부재.
3. **2016–2024 최신 데이터** — 컷오프 해소.
4. **관리 변수**(파종일·품종 성숙군·질소 시비) — 수확량 결정 요인인데 부재.
5. **카운티 경작면적 시계열** — 최적화(2단계)의 x̄ 근사 문제.

## 2. Feature Engineering 진단

**현재 14피처의 한계**
- **시간 해상도** — gdd·edd·ppt가 생육기 총합(또는 7월 1개월). "6월 vs 8월 폭염"을 구분 못 함. 우리 최대 성능 지렛대가 여기였음(7월 가뭄 +0.05, 7월 강수·기온 +0.035).
- **온도 압축** — gdd·edd 2개로 121버킷 압축. 검증 결과 **거의 최적**(버킷 전체 대비 +0.007)이라 이건 한계가 아니라 확인된 강점.
- **VPD·토양수분** — 넣어봤으나 edd·가뭄과 중복이라 이득 ≈0. "남들이 좋다는 것"이 우리 데이터엔 중복.

**추가 시 효과 클 것(예상)**
| 피처 | 근거 | 예상 효과 |
|---|---|---|
| **월별 기온·강수(4~10월)** | 7월 단발도 +0.035였음 | 높음 |
| **위성 NDVI/EVI(생육기)** | 문헌 최상위 예측변수 | 높음 |
| 파종일·품종 | 관리가 수확량 좌우 | 중 |
| 생육단계별(개화·등숙) 집계 | 생리학적 타이밍 | 중 |

**최신 연구 Feature와의 차이**
- 최신(2024–25)은 **위성 시계열(다중분광·다중시점)**을 핵심 입력으로 씀. 우리는 지상 기후·토양 표(tabular)만 사용 → **위성 식생신호 부재가 가장 큰 격차.**

## 3. 모델 구조 진단

**HistGradientBoosting 장점**: 비선형·상호작용 자동 포착(29℃ 꺾임 재현), 결측 native 처리, 빠름, 다중공선성에 강함, 소~중 규모 tabular에서 최강급.

**단점/한계**
- **외삽 불가** — 트리는 학습범위 밖을 못 늘림. 기술추세를 미래로 못 밀어서 시간분할(0.66)이 랜덤CV(0.86)보다 크게 낮음. **이게 성능 천장의 주범.**
- **공간·시간 구조 미인식** — 각 행 독립. 인접 카운티/연속 연도의 구조를 안 씀.
- **점추정** — 불확실성(예측구간) 없음. 실무엔 치명적.
- **과적합 위험** — 버킷 50개를 그냥 더하면 시간분할 하락(0.66→0.645)에서 확인. 피처 과다 시 취약.

**과적합/과소적합**: 현재 14피처는 균형적(랜덤CV와 시간분할 격차는 과적합이 아니라 '외삽 난이도'). 튜닝(SA)으로 +0.007만 나온 걸 보면 **이미 이 피처셋의 천장 근처.**

**다른 모델 대비**: LightGBM/XGBoost/CatBoost는 비슷할 것(부스팅 계열). 선형은 −0.15 열세(비선형 못 잡음). 딥러닝(LSTM/Transformer)은 **위성 시계열이 있을 때** 우위, tabular만으론 GBM이 대체로 대등하거나 우위.

## 4. 검증 방법 진단

**현재**: 3렌즈 정직 보고 — 랜덤 5-fold CV(0.86), GroupKFold 카운티(0.79), 시간분할 2011–15(0.66).

**문제점**
- **랜덤 CV는 낙관 편향** — 같은 카운티가 train/test에 섞여 R²를 ~0.2 부풀림. 대표값으로 쓰면 안 됨(우리는 안 씀, 명시함).
- **시공간 동시 분할 부재** — GroupKFold(공간만)·시간분할(시간만)은 하나씩만 통제. **공간+시간 동시 blocked CV**(안 본 카운티 × 안 본 연도)가 가장 엄격한데 아직 없음.
- **롤링-오리진 부재** — 시간분할이 단일 컷(2011)만. 여러 컷으로 롤링하면 안정성 평가 가능.

## 5. 일반화 성능 진단

- **다른 연도**: 시간분할 0.66 — 미래 예보력은 중간(외삽 한계).
- **다른 지역**: GroupKFold 0.79 — 안 본 카운티엔 꽤 일반화.
- **이상기후(핵심 약점)**: **2012 대가뭄 여전히 +16 과대예측**. 극단해에서 오차가 평년의 2배. 계절총합이 7월 집중 피해를 희석 + 트리가 극단값 외삽 못 함. → **가장 중요한 순간에 가장 약함.**
- **온난화 시나리오**: 관측(warming hole)과 IPCC +2℃ 가정의 불일치. 시나리오는 예측이 아니라 처방으로 명확히 포지셔닝(정직하게 처리됨).

## 7. 실무 적용성 진단

- **해상도**: 카운티 단위 → 개별 농가 필드 의사결정엔 거침.
- **시의성**: 2015 컷오프 + 실시간 파이프라인 없음 → 현재 시즌 예보 불가.
- **불확실성 부재**: 점추정만 → "얼마나 확신하나"를 못 줌(보험·금융엔 필수).
- **범위**: Corn Belt 옥수수 한정 → 타 작물·타 지역 재학습 필요.
- **강점**: 가볍고(초 단위 학습), 재현성(시드 고정), 해석 가능(피처 중요도·인과 FE) → 정책 브리핑·교육용엔 즉시 유용.

## 9. 개선 로드맵 (단기·중기·장기)

### 단기 (추가 데이터 0, 바로 적용) — 며칠
- **S1. 불확실성 예측구간** (V5): `HistGradientBoostingRegressor(loss="quantile")` 또는 conformal. **난이도 낮음 / R² 0, 실무가치 큼.**
- **S2. Spatio-temporal blocked CV** (V6): 안 본 카운티×안 본 연도 동시 분할 지표 추가. **난이도 낮음 / 정직성↑.**
- **S3. 모델 앙상블/스태킹** (LightGBM·CatBoost·GBM 평균): **난이도 낮음 / R² +0.00~0.01(튜닝이 노이즈였던 걸 보면 소폭).**
- **S4. 추세 분리 재설계** (V4): 카운티 선형추세 외삽 + 잔차 ML의 개선판(과거 −0.10은 overshoot 때문 → robust 추세·수축 적용). **난이도 중 / 시간분할 잠재 +0.01~0.03.**

### 중기 (추가 데이터 확보) — 수주
- **M1. 월별 기후(4~10월)** (V2): NOAA nClimDiv 또는 TerraClimate 월별 → 각 달 기온·강수. **난이도 중 / 예상 +0.02~0.05 (7월 단발이 +0.035였음).**
- **M2. 위성 NDVI/EVI** (V3): GEE로 MODIS(2000+)·Sentinel(2015+) 생육기 최대·적분 NDVI를 카운티 집계. **난이도 중~상 / 예상 +0.03~0.08 (문헌 최상위 변수).**
- **M3. 2016–2024 연장** (V7): NASS 수확량 + NOAA 기후. **난이도 중 / 시나리오 정당성 확보 + 학습량↑.**

### 장기 (연구 수준) — 수개월
- **L1. Spatio-temporal DL**(CNN+LSTM/Transformer, CMAViT류): 위성 시계열이 확보된 뒤. **난이도 상 / GBM 대비 우위는 데이터 규모에 의존.**
- **L2. GNN 공간모형**: 카운티 그래프로 공간 상관 명시화. **난이도 상 / 중.**
- **L3. Foundation/Weather 모델 전이**(Prithvi 등): **난이도 최상 / 불확실.**

| **8** | **생육단계별 집계**(개화·등숙) | +0.01~0.03 | 중 | 월별 확보 시 파생으로 저비용, 생리학적 타당 |

| **10** | **Spatio-temporal DL/Transformer** | 불확실(+/−) | **상** | 위성·대량데이터 전제. 그 전엔 GBM이 대등 → 후순위 |

**핵심 권고**: **1·2(월별 기후 + 위성 NDVI)**가 성능의 진짜 지렛대이고, **3·4(불확실성 + 엄격 검증)**는 거의 공짜로 실무·신뢰를 올린다. **딥러닝/Transformer(10위)는 위성 데이터를 먼저 확보한 뒤**에야 ROI가 생긴다 — 지금 당장 도입은 tabular GBM 대비 이득이 불확실하다.
